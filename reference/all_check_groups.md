# List available check group names

Returns the names of all registered check groups. Use these names with
[`checks_by_group()`](https://docs.ropensci.org/goodpractice/reference/checks_by_group.md)
to select checks by group, or with
`options(goodpractice.exclude_check_groups = ...)` to skip groups. Full
descriptions of each check group are return by
[`describe_check_groups()`](https://docs.ropensci.org/goodpractice/reference/describe_check_groups.md).

## Usage

``` r
all_check_groups()
```

## Value

A character vector of check group names.

all_check_groups()
