# Package index

## Main functions

- [`goodpractice-package`](https://docs.ropensci.org/goodpractice/reference/goodpractice-package.md)
  : goodpractice: Advice on R Package Building
- [`gp()`](https://docs.ropensci.org/goodpractice/reference/gp.md) : Run
  good practice checks

## Check control

- [`checks()`](https://docs.ropensci.org/goodpractice/reference/checks.md)
  : List all checks performed
- [`make_prep()`](https://docs.ropensci.org/goodpractice/reference/customization.md)
  [`make_check()`](https://docs.ropensci.org/goodpractice/reference/customization.md)
  : Defining custom preparations and checks
- [`failed_checks()`](https://docs.ropensci.org/goodpractice/reference/failed_checks.md)
  : Names of the failed checks
- [`failed_positions()`](https://docs.ropensci.org/goodpractice/reference/failed_positions.md)
  : Positions of check failures in the source code

## Check groups

- [`all_check_groups()`](https://docs.ropensci.org/goodpractice/reference/all_check_groups.md)
  : List available check group names
- [`all_checks()`](https://docs.ropensci.org/goodpractice/reference/all_checks.md)
  : List the names of all checks
- [`checks_by_group()`](https://docs.ropensci.org/goodpractice/reference/checks_by_group.md)
  : Select checks by check group
- [`default_checks()`](https://docs.ropensci.org/goodpractice/reference/default_checks.md)
  : List the names of default checks (excludes optional check sets)
- [`describe_check()`](https://docs.ropensci.org/goodpractice/reference/describe_check.md)
  : Describe one or more checks
- [`describe_check_groups()`](https://docs.ropensci.org/goodpractice/reference/describe_check_groups.md)
  : Describe available check groups
- [`tidyverse_checks()`](https://docs.ropensci.org/goodpractice/reference/tidyverse_checks.md)
  : List the names of tidyverse style checks

## Agent skills

- [`learn_skill_gp()`](https://docs.ropensci.org/goodpractice/reference/learn_skill_gp.md)
  : Function for AI agents to run and learn how to use the
  'goodpractice' package.
- [`use_skill_gp()`](https://docs.ropensci.org/goodpractice/reference/use_skill_gp.md)
  : Download a local copy of 'goodpractice4agents.md' to tell AI agents
  how to use this package.

## Output control

- [`export_json()`](https://docs.ropensci.org/goodpractice/reference/export_json.md)
  : Export failed checks to JSON
- [`print(`*`<goodPractice>`*`)`](https://docs.ropensci.org/goodpractice/reference/print.goodPractice.md)
  : Print goodpractice results
- [`results()`](https://docs.ropensci.org/goodpractice/reference/results.md)
  : Return all check results in a data frame
